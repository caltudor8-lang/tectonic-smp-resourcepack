# Tectonic SMP texture pack

The resource pack the Tectonic SMP server sends to players when they join: the Scythe,
Crown, Drills, egg hunt prizes and season icons. It's built by the TectonicRelics plugin
(`build/generated-pack/TectonicRelics-ResourcePack.zip`) and updated here with
`publish-pack.sh` in that repo. Players never need to download it by hand.
